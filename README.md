A one-page newspaper that sums up the world's news of **Sunday, 22 November 2026**: Iran's strike on a US base in Bahrain, the missile hit on Lviv, the EU–Indonesia trade deal, the stalled COP31 climate talks, flooding in Gaza, and the capture of cartel boss "El Chapo Isidro" — plus the day's other headlines in an "Also today" strip.

## Run it

```sh
python3 generate.py   # redraw entry.png from scratch (needs Pillow + Noto/DejaVu fonts)
python3 main.py       # copies entry.png to /output/entry.png
```

`main.py` uses only the standard library, makes no network calls, and writes the same bytes on every run.
